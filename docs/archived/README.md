# Archived docs — historical, not maintained

These are superseded internal notes, kept for history. **They are not current and
are not maintained.** The live state of the site is, in order: the **git log** →
the **rendered content under `src/content/docs/`** → the **memory system**. Trust
that record, never these files.

| File | Was | Why archived |
|---|---|---|
| `PROGRESS.md` | per-post narrative-arc tracker | drifted — marked *published* posts as in-progress; the deployed site is the record now |
| `TIMELINE.md` | cross-repo commit-level timeline | frozen at Feb 2026; the live timeline is `git log` |
| `CONTENT-TRACKER.md` | content status table | placeholders for content long since live |
| `PLAN.md` | the original pre-build site plan | the site grew past it |

Recover any of them in full from git history — nothing is lost:
`git show <rev>:docs/archived/<file>`.

The **active** docs are one level up: `WRITING-GUIDE.md` (the voice anchor consonare
casts against) and `COMPACTION-AMNESIA-RECOVERY.md` (the recovery map).
