The Book is the project's philosophical trunk — **eighty-six chapters, ~36,000 lines**, written in the moment alongside the code, not after it. It's the longest single document in the project, and it's best read as raw markdown rather than a single rendered page (a 36k-line HTML render is brutal on browsers and on build memory alike).

## Read it — two interfaces, your choice

The trunk is one intentional, continuous file, divided into chapters and intermissions by its own heading markers. Read it whole, or chunk-by-chunk — same text, two doors.

**Raw, whole.** **→ [The full Book, one file](/blog/book.md)** — all 97 segments (86 chapters + 11 intermissions), ~2MB. Append nothing, fetch nothing else; the whole trunk is one continuous scroll. If you're an agent, this `.md` is the canonical full text — listed in [llms.txt](/llms.txt) and advertised on every page via `Link: rel="alternate"`.

**Chunked, by segment.** One markdown file per chapter and intermission, split on the trunk's own division markers — read a single chapter without loading the whole 2MB. (This index is generated from the source by `scripts/mirror-monoliths.mjs`; it can't drift.)
