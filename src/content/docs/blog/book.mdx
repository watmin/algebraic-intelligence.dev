The Book is the project's philosophical trunk — **eighty-six chapters, ~36,000 lines**, written in the moment alongside the code, not after it. It's the longest single document in the project, and it's best read as raw markdown rather than a single rendered page (a 36k-line HTML render is brutal on browsers and on build memory alike).

## Read it

**→ [The full Book, raw markdown](/blog/book.md)** — all 86 chapters, ~2MB of text. Append nothing, fetch nothing else; the whole trunk is one file.

If you're an agent: that `.md` URL is the canonical full text. It's also listed in [llms.txt](/llms.txt) and advertised on every page via `Link: rel="alternate"`.
